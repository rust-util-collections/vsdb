# VSDB agent instructions

Read `CLAUDE.md` before working in this repository and follow its shared
engineering and compatibility policies.

For Rust edits, dependency updates and releases, apply the MMDB-aligned
minimum Rust version and validation rules in
`.claude/docs/compatibility-policy.md` (Rust toolchain policy). Read
`../mmdb/Cargo.toml`; the latest-stable channel and the locally installed
compiler are not the MSRV authority.
